Milestone A — the spine is playable

STARWEFT

A single-shard, player-driven sandbox space MMO. Original universe, original factions, original ships — inspired by the design principles of the genre, built entirely from scratch. Mining, manufacturing, trading, and combat all run on a real authoritative server with a real economy, and you can fly it right now from a terminal.

Play it

git clone https://github.com/ishamustafaomar/EVE-Online.git
cd EVE-Online
pnpm install
pnpm play

Hosts a local universe and drops you into a command prompt — look, undock, fit mining, goto b11, mine 1 3, market ammo.ferro-slug. Run pnpm play --name "Someone Else" from a second terminal to join the same universe as another pilot.

Design pillars

One world, one history

A single persistent shard. No instanced copies — everyone shares the same consequences.

The economy is the game

Ships and modules are player-built from player-mined resources. Prices emerge from order books, never set by the server.

Risk is priced in

Reward scales with danger. Losses are real, which is what makes industry and victory mean something.

Depth over reflexes

Fights are won by fitting, positioning, and energy management — not aim. No client-side hit registration, ever.
